File Reference

File Reference

All exchanged files share the interface envelope Version="1.1". Import files use the root element <PPSImport>; export files use <PPSExport>.

File (pattern) Root element Direction Purpose

ProdOrderImp*.xml

PPSImport

(IN)

Create, update or cancel production orders; carry part master data. §5

StockImp*.xml

PPSImport

(IN)

Material stock sync — absolute (TotalStock) or delta (InventoryBooking). §8

JobExp*.xml

PPSExport

(OUT)

Job feedback: sheets, parts-on-sheet, times, waste. §9

ProdOrderExp.xml

PPSExport

(OUT)

Order feedback — e.g. denial of an update/cancel that arrived too late. §7

<Job>.xml + .LST + setup plan

ProductionPackage

(OUT)

Full production package (NC data, technology tables) published for the machine / plant. §10

Spreadsheet equivalents (.csv, .xls, .xlsx) may be used in place of the XML import files; they are mapped through the same dialog described in §6.
