PPS Interface — Technical Manual

The PPS interface is a file-based XML / spreadsheet interface that connects an external ERP / production-planning system (PPS) to the sheet-metal nesting & production software — for order import, material synchronization, and job feedback.

At a glance

  • Transport: file exchange (XML CSV XLS XLSX)

  • Interface version: 1.1

  • Directions: import & export

  • Audience: integrators & administrators
